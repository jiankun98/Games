# Games

小游戏合集（Canvas + TypeScript）。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js
```

启动后访问总入口（游戏展厅，列出所有游戏，点击进入）：<http://localhost:5173/>

各游戏页右上角均有「← 主页」可返回展厅。

## 1. n 子棋（n >= 4）

五子棋 / 六子棋等，支持 **人人对战** 与 **人机对战（大模型）**，落子历史与 AI 思考过程可记录、复盘、导出。

启动后访问： <http://localhost:5173/games/gobang/game.html>

### 配置大模型（人机对战）

进入页面右侧「大模型」页签：

1. 选择服务商预设（DeepSeek / Moonshot / 通义 Qwen / 智谱 GLM / OpenAI / Ollama 本地 / 自定义），或自行填写 **Base URL**、**API Key**、**模型**。
2. 选择调用方式：
   - **代理（默认）**：经本地服务 `/api/llm` 转发，规避浏览器 CORS，推荐。
   - **直连**：浏览器直接请求大模型，仅适用于允许跨域的服务（DeepSeek、Moonshot、本地 Ollama 等）。
3. 点击「测试连接」确认可用，再「保存配置」。
4. 回到「对局」页签，选择「人机对战」、AI 执子颜色、棋盘规格与连子数，点「开始新对局」。

> 任意 **OpenAI 兼容** 的 `/chat/completions` 接口均可使用。密钥仅存于浏览器 localStorage；若希望密钥不入浏览器，可在 `run/config.json` 写入 `{"baseUrl":"...","apiKey":"..."}`（该文件已 gitignore），服务端会优先使用。

### 复盘

- 「复盘 / 记录」页签提供单步前进/后退、自动播放、跳到开局/终局。
- 点击「走子记录」任一手，棋盘回到该局面并展示该步 AI 的思考过程。
- 支持「导出对局」为 JSON 与「导入对局」继续复盘。

### 文件结构

- `games/gobang/index.ts` / `index.js` — 棋盘引擎（渲染、判胜、历史、复盘、兜底启发式）
- `games/gobang/game.html` — 对局页面与 UI、大模型调用与流式解析
- `run/game.js` — 本地静态服务 + OpenAI 兼容流式代理

## 3. 人生模拟器（像素版）

从出生到终老的人生模拟器：掷初始属性、选天赋，逐年经历随机事件并做出选择，最终获得人生评级。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js，托管静态文件
```

启动后访问：<http://localhost:5173/games/life/game.html>

### 玩法

1. **角色创建**：掷出四项初始属性（颜值 / 智力 / 体质 / 家境，可重掷），从随机三个天赋中三选一（如「富二代」「神童」「锦鲤」「长寿基因」等，带专属加成）。
2. **度过一生**：每过一岁触发一个随机事件（出生、上学、初恋、高考、工作、婚姻、买房、退休、百岁寿辰……），点击选项决定如何应对，选项会影响各项属性、金钱与心情。
3. **自动模式**：点「⏩ 自动」可让 AI 按启发式自动选择、快进人生；支持键盘 `1-4` 选选项、`Enter` 进入下一年。
4. **人生终结**：体质归零、年迈体衰或遭遇意外即离世，结算给出 **S~F 评级**与人生称号（传奇人生 / 辉煌人生 / 平凡人生 / 摆烂王者……），并回放完整一生轨迹。

### 文件结构

- `games/life/index.js` - 游戏引擎（像素角色渲染、事件/天赋数据、人生状态机、评级结算）
- `games/life/game.html` - 像素风界面（HUD、属性条、事件日志、选项、创建/结算弹窗）

> 像素角色与场景使用 Canvas 程序化绘制，随人生阶段（婴儿 / 童年 / 少年 / 成年 / 老年）切换造型与背景，带呼吸、眨眼动画。

## 4. 族谱·传家（家族传承模拟）

从单人开局，世代婚配繁衍，逐步壮大一族血脉。含收支经济、树状族谱可视化与终结评级。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js，托管静态文件
```

启动后访问：<http://localhost:5173/games/lineage/game.html>

手机版（独立页面，触屏适配、双指缩放）：<http://localhost:5173/games/lineage/mobile.html>

### 玩法

1. **开基立业**：择姓氏、定性别、选出身（寒门 / 小康 / 富户，决定起始家产），立族开宗。
2. **自动演进 + 事件弹窗**：时间线默认自动推进（约 1.6 秒/年，节奏舒缓）。每当出现影响收入或人口的事务——
   - **提亲**：族人成年后有人上门议亲，权衡聘礼与对方门第，应亲或婉拒（亦可在详情面板主动「为之说媒」）。
   - **择业**：族人弱冠需择立身之道，可送太学（2000 贯）解锁文官/医者/侍郎等高薪仕途。
   - **染疾 / 天灾 / 瘟疫 / 征役 / 盗匪 / 商机 / 收养 / 续弦** 等随机事件，需亲自抉择后方继续推进——时间线遇事即停，抉择后才流转。
   - **添丁 / 辞世** 等则以浮动通知提示，不打断节奏。
   - **经济**：成年族人按职业产出岁入，全体消耗口粮；家道中落（入不敷出）时死亡率上升。
3. **族谱树**：中央可缩放（滚轮 / ＋－按钮）、可拖拽平移的家族树，朱砂横线表示连理、墨线表示血脉传承；外姓嫁入者虚线边框、原姓标注；点选族人查看详情。可随时「⏸ 暂停」手动细看，或「推进一年」单步。
4. **终卷评级**：族中再无活口或债台高筑即落幕，按世代数、族人数、鼎盛家产等给出 **S~F 评级**与族号（百年望族 / 钟鸣鼎食 / 诗礼传家 / 寻常人家……），并附族谱后记。

### 文件结构

- `games/lineage/index.js` - 引擎（人物/家族模型、年度演算、递归树布局、SVG 像章肖像、缩放平移、事件池与弹窗决策、终卷结算）
- `games/lineage/game.html` - 宣纸/水墨/金线中式美学界面（顶栏 HUD、家族树视图、详情/家乘侧栏、事件弹窗、浮动通知、开局与终卷弹窗）
- `games/lineage/mobile.html` - 手机版独立页面（复用同一引擎；紧凑顶栏 + HUD 条、全屏族谱树、底部抽屉切换详情/家乘、触屏拖拽与双指缩放）

> 族人肖像由 SVG 程序化生成（依个体种子固定面容、随性别/年岁/生死变化）；族谱连线与卡片采用朱砂、墨、金三色体系，整体呈卷轴族谱质感。
