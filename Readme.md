# Games

小游戏合集（Canvas + TypeScript）。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js
```

启动后访问总入口（游戏展厅，列出所有游戏，点击进入）：<http://localhost:5173/>

各游戏页右上角均有「← 主页」可返回展厅。

## 1. n 子棋（n >= 4）

五子棋 / 六子棋等，支持 **人人对战** 与 **人机对战（大模型）**，落子历史与 AI 思考过程可记录、复盘、导出。

启动后访问： <http://localhost:5173/games/gobang/game.html>

### 配置大模型（人机对战）

进入页面右侧「大模型」页签：

1. 选择服务商预设（DeepSeek / Moonshot / 通义 Qwen / 智谱 GLM / OpenAI / Ollama 本地 / 自定义），或自行填写 **Base URL**、**API Key**、**模型**。
2. 选择调用方式：
   - **代理（默认）**：经本地服务 `/api/llm` 转发，规避浏览器 CORS，推荐。
   - **直连**：浏览器直接请求大模型，仅适用于允许跨域的服务（DeepSeek、Moonshot、本地 Ollama 等）。
3. 点击「测试连接」确认可用，再「保存配置」。
4. 回到「对局」页签，选择「人机对战」、AI 执子颜色、棋盘规格与连子数，点「开始新对局」。

> 任意 **OpenAI 兼容** 的 `/chat/completions` 接口均可使用。密钥仅存于浏览器 localStorage；若希望密钥不入浏览器，可在 `run/config.json` 写入 `{"baseUrl":"...","apiKey":"..."}`（该文件已 gitignore），服务端会优先使用。

### 复盘

- 「复盘 / 记录」页签提供单步前进/后退、自动播放、跳到开局/终局。
- 点击「走子记录」任一手，棋盘回到该局面并展示该步 AI 的思考过程。
- 支持「导出对局」为 JSON 与「导入对局」继续复盘。

### 文件结构

- `games/gobang/index.ts` / `index.js` — 棋盘引擎（渲染、判胜、历史、复盘、兜底启发式）
- `games/gobang/game.html` — 对局页面与 UI、大模型调用与流式解析
- `run/game.js` — 本地静态服务 + OpenAI 兼容流式代理

## 3. 人生模拟器（像素版）

从出生到终老的人生模拟器：掷初始属性、选天赋，逐年经历随机事件并做出选择，最终获得人生评级。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js，托管静态文件
```

启动后访问：<http://localhost:5173/games/life/game.html>

### 玩法

1. **角色创建**：掷出四项初始属性（颜值 / 智力 / 体质 / 家境，可重掷），从随机三个天赋中三选一（如「富二代」「神童」「锦鲤」「长寿基因」等，带专属加成）。
2. **度过一生**：每过一岁触发一个随机事件（出生、上学、初恋、高考、工作、婚姻、买房、退休、百岁寿辰……），点击选项决定如何应对，选项会影响各项属性、金钱与心情。
3. **自动模式**：点「⏩ 自动」可让 AI 按启发式自动选择、快进人生；支持键盘 `1-4` 选选项、`Enter` 进入下一年。
4. **人生终结**：体质归零、年迈体衰或遭遇意外即离世，结算给出 **S~F 评级**与人生称号（传奇人生 / 辉煌人生 / 平凡人生 / 摆烂王者……），并回放完整一生轨迹。

### 文件结构

- `games/life/index.js` - 游戏引擎（像素角色渲染、事件/天赋数据、人生状态机、评级结算）
- `games/life/game.html` - 像素风界面（HUD、属性条、事件日志、选项、创建/结算弹窗）

> 像素角色与场景使用 Canvas 程序化绘制，随人生阶段（婴儿 / 童年 / 少年 / 成年 / 老年）切换造型与背景，带呼吸、眨眼动画。

## 4. 族谱·传家（家族传承模拟）

从单人开局，世代婚配繁衍，逐步壮大一族血脉。含收支经济、树状族谱可视化与终结评级。

### 运行

```bash
pnpm install        # 安装依赖（express）
npm start           # 等价于 node run/game.js，托管静态文件
```

启动后访问：<http://localhost:5173/games/lineage/game.html>

手机版（独立页面，触屏适配、双指缩放）：<http://localhost:5173/games/lineage/mobile.html>

### 玩法

1. **开基立业**：择姓氏、定性别、选出身（寒门 / 小康 / 富户，决定起始家产），立族开宗。
2. **自动演进 + 事件弹窗**：时间线默认自动推进（约 1.6 秒/年，节奏舒缓）。每当出现影响收入或人口的事务——
   - **提亲**：族人成年后有人上门议亲，权衡聘礼与对方门第，应亲或婉拒（亦可在详情面板主动「为之说媒」）。
   - **择业**：族人弱冠需择立身之道，可送太学（2000 贯）解锁文官/医者/侍郎等高薪仕途。
   - **染疾 / 天灾 / 瘟疫 / 征役 / 盗匪 / 商机 / 收养 / 续弦** 等随机事件，需亲自抉择后方继续推进——时间线遇事即停，抉择后才流转。
   - **添丁 / 辞世** 等则以浮动通知提示，不打断节奏。
   - **经济**：成年族人按职业产出岁入，全体消耗口粮；家道中落（入不敷出）时死亡率上升。
3. **族谱树**：中央可缩放（滚轮 / ＋－按钮）、可拖拽平移的家族树，朱砂横线表示连理、墨线表示血脉传承；外姓嫁入者虚线边框、原姓标注；点选族人查看详情。可随时「⏸ 暂停」手动细看，或「推进一年」单步。
4. **终卷评级**：族中再无活口或债台高筑即落幕，按世代数、族人数、鼎盛家产等给出 **S~F 评级**与族号（百年望族 / 钟鸣鼎食 / 诗礼传家 / 寻常人家……），并附族谱后记。

### 文件结构

- `games/lineage/index.js` - 引擎（人物/家族模型、年度演算、递归树布局、SVG 像章肖像、缩放平移、事件池与弹窗决策、终卷结算）
- `games/lineage/game.html` - 宣纸/水墨/金线中式美学界面（顶栏 HUD、家族树视图、详情/家乘侧栏、事件弹窗、浮动通知、开局与终卷弹窗）
- `games/lineage/mobile.html` - 手机版独立页面（复用同一引擎；紧凑顶栏 + HUD 条、全屏族谱树、底部抽屉切换详情/家乘、触屏拖拽与双指缩放）

> 族人肖像由 SVG 程序化生成（依个体种子固定面容、随性别/年岁/生死变化）；族谱连线与卡片采用朱砂、墨、金三色体系，整体呈卷轴族谱质感。

## 5. 游戏王·决斗对战（2D / 3D）

经典规则卡牌决斗：通常召唤 / 祭品召唤 / 翻转召唤 / 特殊召唤，战斗与连锁响应，魔法·陷阱·反击陷阱，事件订阅式引擎驱动，内置启发式 AI 对手。共 **149 张**卡（青眼白龙、黑魔术师、元素英雄、吸血鬼领主……），全部收录官方卡密与卡图立绘。

### 运行

```bash
pnpm install        # 安装依赖（express、three）
npm start           # 等价于 node run/game.js
```

2D 版：<http://localhost:5173/games/YuGiOh/game.html>

3D 版（Three.js 立体决斗台，拖拽旋转视角）：<http://localhost:5173/games/YuGiOh/game3d.html>

### 玩法

1. **选择卡组**：11 套预设卡组（经典 / 元素英雄 / 机械族 / 青眼白龙 / 黑魔术师 / 真红眼黑龙 / 神鹰女郎 / 磁石战士 / 战士族 / 不死族 / 天使族），双方各选一套开局。卡组上限 60 张，怪兽·魔法·陷阱按均衡比例配比（怪兽约 55%，其中 1-4 星约 75%）。
2. **回合推进**：抽卡 → 准备 → 主要1 → 战斗 → 主要2 → 结束；先手首回合不抽卡、不能攻击。
3. **召唤与操作**：4 星以下直接通常召唤，5-6 星需 1 只祭品、7 星以上需 2 只；可覆盖怪兽（里侧守备）、覆盖魔法·陷阱；点击卡牌弹出菜单执行 召唤 / 覆盖 / 发动效果 / 切换表示 / 攻击 等操作。发动条件不满足的卡不会出现「发动」选项。
4. **连锁**：召唤 / 攻击宣言 / 伤害计算时可发动陷阱与反击陷阱连锁（魔法筒、神圣防护罩、落穴、神之宣告……），连锁逆序结算。
5. **节奏与音效**：三档节奏（快速 / 标准 / 悠闲）、音效开关、对局日志与内嵌「说明」规则。

3D 版基于 Three.js：怪兽区 / 魔陷区分行立体摆放，卡牌立绘纹理实时渲染，点击卡牌查看操作、水平拖拽旋转视角，带粒子与伤害特效。

### 卡密与立绘

- 卡密数据由 YGOProDeck 官方 API 校准（`run/fetch-passwords.js` 可重跑校验，149 张卡图全部可用）。
- 3D 版卡图经本地 `/api/img` 代理转发（域名白名单，规避 CORS 与 Canvas 纹理污染）；2D 版直连图源。

### 文件结构（ES Module：引擎与 UI 均为 .mjs，无打包器）

- `games/YuGiOh/cards.mjs` — 卡牌数据与效果声明（149 张卡、11 套卡组预设；triggers / continuous）
- `games/YuGiOh/engine/` — 决斗引擎：`duel.mjs` 门面 + 九个子模块（state / prompt / events / chain / turn / summon / action / battle / api）+ `boot.mjs`（2D 页全局兼容层）
- `games/YuGiOh/ai-player.mjs` / `llm-player.mjs` — 启发式 AI / 大模型对手（同一 5 回调契约）
- `games/YuGiOh/game.html` — 2D 对局界面
- `games/YuGiOh/game3d.html` + `game3d.css` + `games/YuGiOh/ui3d/` — 3D 对局界面（薄入口 + 九模块：store/labels/sfx/domfx/scene/hud/actions/fxevent/main）
- `run/test-*.mjs`（7 个回归测试）与 `run/check-decks.mjs`（卡组校验）— node 直跑
- `games/YuGiOh/ENGINE.md` — 引擎与 3D UI 实现文档（事件定义 / 状态参数 / 调用链）

## 7. 赵云与阿斗（水墨文字塔防 · 无尽）

致敬爆款小程序《赵云与阿斗》的文字合成塔防：召唤汉字 → 兵营布阵 → 同类同级合并升级 → 碎片凑名激活魏蜀吴 16 名武将，守护阿斗迎战无尽波次。全水墨文字美术（宣纸底、墨字变形战斗、水墨泼洒大招），零图片素材，纯 Canvas 程序化绘制。

启动后访问：<http://localhost:5173/games/zhaoyun/game.html>

### 玩法

1. **征兵布阵**：点「征兵」消耗馒头（10 起每次 +2），**一次征满 5 个字**并重新随机待命区——刀（近战快攻）/ 枪（直线穿透）/ 剑（范围溅射）/ 弓（远程高伤）四种兵种字，外加武将碎片字与铲子。战场为 **15×10 网格**，格子分三类：**道路格**（深墨蛇形三横道，敌军沿格子中心行进）、**布置格**（亮色，初始 20 个成片分布）、**未开发格**（荒地，拖铲子开垦为布置格，后期持续扩展）。
2. **拖拽规则**：**待命区 ↔ 待命区**同类同级拖到一起二合一升级（最高 7 级），不同字互换位置排序；**待命区 ↔ 场上**可互相拖放；拖入「弃」出售周转。敌军以亮色纸牌底块 + 红血条行走于深墨道路，一望即明。
3. **武将激活**：碎片凑齐全名两字同场（如 赵+云、关+羽）拖到一起，即激活强力武将，自带定时大招——赵云「七进七出」全路径突进、张飞「当阳咆哮」全屏眩晕、黄忠「火箭烈」箭雨、曹操「乱世奸雄」、周瑜「火烧赤壁」火海…… 共 16 名（金/紫/蓝/绿四品质），共享字（张、黄）可跨势力拼合。武将靠击杀积累经验升级。
4. **Boss 与道具**：每 5 波出 Boss（华雄·疾冲 / 颜良文丑·双生分裂 / 吕布·无双狂暴 / 张郃·无敌 / 曹仁·护盾，轮换增强）。守过 Boss 波随机抽取道具：被动（攻速符/兵书/军粮/招贤令）即时叠加生效；主动（毛笔改字/战鼓/仁心丹/火计）装入道具栏，点击或按 Q/W 释放。
5. **无尽挑战**：敌军血量随波次线性转指数增长（前期容错、后期必现崩盘），比拼存活波数；击杀与波次犒赏馒头，召唤费用逐次递增。阿斗 5 心，心尽结算。最高纪录与武将图鉴存于 localStorage。

### 文件结构

- `games/zhaoyun/data.js` — 纯配置：15×10 网格地图 / 兵种 / 16 名武将技能 / 杂兵与 6 Boss / 无尽波次曲线 / 召唤池（一次 5 字）/ 道具表
- `games/zhaoyun/index.js` — 引擎（网格战场状态机 / 波次与 Boss / 索敌与四种弹道 / 待命区与场上双向拖拽合并 / 武将激活与技能 / 道具 / 粒子动效 / 等比缩放渲染）
- `games/zhaoyun/game.html` — 对局页面（深墨顶栏 HUD / 待命区 / 弃置区 / 道具栏 / 卷轴抽道具 / 图鉴 / 说明 / 结算弹窗）
- `run/test-zhaoyun.js` — 数值平衡回归（node 直跑）：挂机应死于第 1 波、自动策略存活 8~30 波、满配阵容 30+ 波出现无尽崩盘点

> 敌我全部以汉字呈现：静止时为墨字，接敌后字形变形参战（弓字后仰蓄力、枪字前倾突刺）；命中溅墨、大招全屏水墨泼洒配大字特写。引擎核心与渲染分离设计，数值模拟可在 node 中同步跑。

## 8. 商业帝国（从零到万亿 · 移动版）

休闲手游风格（暖金财富主题）的慢节奏放置经营游戏（Vite + Vue 3 重写，原 Canvas 版已移除）：开局 3.1 万元，开第一家便利店起步，通过门店扩张、股票分红、房产收租、奢侈品波段交易，把身家从 **1** 滚到 **万亿**（乃至亿亿）登顶世界首富。界面为游戏化两级结构——顶部玩家 HUD（称号/总资产/现金流）+ 各模块入口大卡 → 子页面（右滑入、可返回），一屏一焦点、低信息密度；全模块税收机制、自动存档 + 离线收益，后续可封装安卓 App。

启动后访问：<http://localhost:5173/games/empire/dist/index.html>（开发调试：`cd games/empire && pnpm install && pnpm dev`，端口 5174）

### 玩法（底部六导航：股票 / 房产 / 产业 / 余额 / 购物 / 总览）

1. **产业（9 类公司）**：便利店为零风险入门（3 万开设、利润直进主账户）；另设 PRD 8 家深度经营公司——快递(20万)/银行(50万)/租车(100万)/房地产(500万)/汽车经销商(2000万)/信息技术(1亿)/石油能源(10亿)/俱乐部(50亿)，按现实小时结算。
   - **独立公司池**：8 家公司收支走自有现金池，可注资/分红；池亏空即停摆（产出与成本冻结、不累积债务），注资恢复；**无强制清算，可以一直亏**（银行利率错配、IT 项目沉没、勘探打水漂、球员高薪都是真实亏损源）
   - **评级 E~SSS**：按累计净利润升档，解锁更高档载具/项目/品牌/金库；详情页显示下一级解锁预告
   - **上市/集团/清算**：A 级+估值 10 亿可上市（IPO 注资 50%、市值每小时 ±1% 波动、增发/回购退市）；≥3 家上市公司可组建集团（收益 +10%、成本 -10%、市值 ×1.2）；主动清算（遣散赔偿、剩余池返还、固定资产 40% 拍卖按价值 1~5h 到账、欠薪触发声誉 debuff）
   - 各公司机制要点：快递/租车买载具产金+里程维修+车位建造计时（飞机占机位）；银行双利率滑杆赚息差；房地产建筑队+项目开发；经销商每小时刷二手车收修卖（车间并发受限）；IT 雇团队研发四节点随机事件+运营衰减；石油勘探+平台开采+油价周期囤油套利；俱乐部青训+转会+实力对抗胜率
   - 公司经营新闻事件（快递旺季/油价暴跌等）短期影响全部公司利润
   - **等待时间总则**：所有等待上限 5 现实小时，且按价值递增——快递/租车维修 1~5h（按载具价值）、房地产项目 1~5h（按项目价值，每小时利润保持不变）、IT 研发 1~5h、经销商维修最长 4.8h（损耗×品牌档系数）、车位 1h/机位 4h 建造、青训 4h 产员、油价 4h 波动、清算拍卖按款额 1~5h 到账
2. **股票（45 支）**：国内 30 + 海外 15（海外高波动低股息）；每个游戏日（120 秒）按持仓×股价×股息率分红；卖出印花税 0.1%、股息税 10%。
3. **房产（10 种）**：国内 7 + 海外 3；买入契税 1.5%、卖出综合税 5%、租金税 10%。
4. **购物（5 类 32 件）**：汽车/飞机/游艇/古董/名牌波段交易；买入消费税 3%、卖出交易税 2%。
5. **余额**：银行卡样式展示现金、每小时净现金流与收支流水。
6. **总览**：总资产构成、现金流、累计纳税、称号进度、存档导出/导入/重置。
7. **经济节奏**（休闲模拟实测，便利店+快递+股票+房产）：5 天 ~100 万 → 15 天 ~2500 万 → **~21 天破 1 亿（约一个月）** → 70 天破万亿 → 亿亿级延伸。回本锚：入门资产 20~40 现实小时、高阶 60~130 小时；离线按 35% 效率结算（24h 封顶，项目/研发/维修照常推进）。
