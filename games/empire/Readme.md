# 《商业帝国》产业模块

基于 PRD（8 家公司 + 独立账本亏损机制 + 评级 + 上市/集团 + 主动清算）实现。

## 九类公司

| 公司 | 开设费 | 核心机制 |
|---|---|---|
| 🏪 便利店 | 3 万 | 零风险入门，门店扩张，利润直进主账户 |
| 🚚 快递 | 20 万 | 30 档载具/货机产金，里程满维修停机，车位/机位扩展 |
| 🏦 银行 | 50 万 | 存贷双利率滑杆，息差每小时结算，利率错配即净亏 |
| 🚗 租车 | 100 万 | 30 款车型时租，200h 维修，车库扩容 |
| 🏗️ 房地产 | 500 万 | 建筑队（忙队工资 5 万/时），30 项目开发售楼回款 |
| 🚘 经销商 | 2000 万 | 每小时刷 3 辆二手车，收购→维修→出售赚差价 |
| 💻 信息技术 | 1 亿 | 团队工资+30 作品研发，四节点随机事件，运营衰减 |

| ⚽ 俱乐部 | 50 亿 | 青训/转会/训练赛/赞助/门票，战绩差持续失血 |

## 核心系统

- **独立公司现金池**：8 家新公司收支走 `st.treasury`；池空 → 停摆（产出冻结、不累积债务），注资即恢复；分红/注资为通用操作
- **评级 E~SSS**：累计净利润达 `[100万,1000万,1亿,10亿,100亿,500亿,2000亿]` 升档，解锁更高档项目/载具/品牌
- **上市/集团**：A 级 + 估值 10 亿可上市（IPO 注入 50% 进池、市值 ±1% 波动）；增发/回购退市；≥3 家上市公司组集团（收益 +10%、成本 -10%、市值 ×1.2）
- **主动清算**：遣散赔偿（不足 → 声誉 debuff：全公司开设费 +10% 持续 168h）→ 资产 40% 拍卖 → 移除公司
- **清单 30 项**：快递载具/租车车型/房地产项目/经销商品牌/信息技术作品统一 30 项，阶梯式费用（几何递增），回本周期入门 ~30h、高端 ~80h

## 架构

```
src/industries/
  base.js       # 评级、公司池工具、机队基类
  registry.js   # typeId -> handler 注册表
  cstore.js     # 便利店
  bank.js / express.js / rental.js / realestate.js
  dealer.js / itcorp.js / oil.js / club.js
  ipo.js        # 上市/集团/主动清算（横切）
src/engine.js   # v3：小时结算（_acc.hour）、公司池计税/停摆、快照、存档迁移
```

- 存档 v3；v2 旧档（含便利店）自动迁移（stores → st.stores，旧类型自动丢弃）
- 8 家新公司每现实小时结算一次（tickHour）；便利店按游戏日结算
