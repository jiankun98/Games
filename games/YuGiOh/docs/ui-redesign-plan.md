# 游戏王 3D · 真实游戏感 UI 改造调研与方案

> 目标：保留现有 3D 对场，把 DOM 层 UI 升级到商业卡牌游戏（Master Duel / Duel Links 级别）的观感与演出感。

## 一、调研：真实游戏王对战 UI 的构成要素

### 1. Master Duel（KONAMI，标杆）
- **视觉基调**：深色（近黑蓝）竞技场空间，视觉焦点永远在卡牌上；UI 用金属渐变+细描边+微光晕的"仪式感"装饰
- **LP 显示**：屏幕对角的斜切平行四边形大血条，窄体大数字（DIN 类字体）；扣血时数字滚动 + 红闪 + 碎片飞溅；位置可自定义浮动
- **阶段流程**：侧边竖排 6 个阶段图标（抽卡→准备→主要1→战斗→主要2→结束），当前阶段高亮；切换有横幅扫过动画
- **卡牌发动演出**：王牌怪兽有全屏专属召唤动画；普通召唤也有光柱/光圈；发动卡时卡牌放大居中展示（卡图+名称横幅）
- **卡牌详情**：悬停出大图预览，卡框按类型着色（怪兽金棕 / 魔法绿 / 陷阱紫），ATK/DEF 用专属徽章呈现
- **交互反馈**：可选目标红框脉冲、连锁堆叠图标、所有状态变化均有 300–600ms 缓动
- **字体**：数字用窄体、标题用带衬线西文（庄重感）+ 黑体中文

### 2. Duel Links
- 更明亮简洁、卡牌大图优先、操作按钮大而少——移动端友好路线

### 3. 社区共识痛点（我们要避开的坑）
- 点击次数过多（我们刚把召唤改成免选格，方向正确）
- 界面元素杂乱、缺少阶段流程可视化（Reddit 上对"两段式阶段按钮"的批评）
- 教学信息缺失（首次进入引导）

## 二、现状盘点

已有底子（不需要动的）：
- 深蓝 + 金色主题（与 Master Duel 同色系）✓
- 3D 对场 + 上下 LP 血条 + 回合条 + 三栏卡组选择 + 卡牌预览 + 日志面板
- 拖拽召唤/修饰键、免选格召唤等交互流程
- 47 处 CSS 动画/过渡（有基础动效意识）

十个主要差距（按观感影响排序）：
1. **没有演出层**：回合/阶段切换、召唤、发动都没有"横幅/居中卡牌展示"类演出——这是与真实游戏最大的观感差距
2. **结算界面太素**：胜利/失败只有一行字+按钮，没有全屏演出
3. **LP 血条朴素**：普通圆角条，缺斜切造型、金属质感、图标、扣血碎片飞溅
4. **回合条无流程感**：纯按钮排，没有 6 阶段进度可视化
5. **卡牌操作菜单朴素**：纯文字列表，无卡面缩略、类型色条、图标
6. **卡牌预览弱**：小图无框色变化，ATK/DEF 无徽章化
7. **3D 场景缺装饰**：无决斗盘边框、卡垫纹理、氛围光
8. **召唤/发动缺 3D 特效**：无光柱、无镜头运镜
9. **字体单一**：缺庄重感的西文标题字（数字字体 Bahnschrift 已就位）
10. **伤害数字缺失**：扣血只有红闪，无飞溅数字

## 三、改造方案（四档，可独立实施）

### B. 演出层（效果最明显，建议先做）
| 项目 | 说明 | 技术 |
|---|---|---|
| 回合横幅 | 回合开始/阶段切换时全屏横幅扫过（"你的回合"/"战斗阶段"），带擦除动画与音效 | CSS keyframes + 现有 phase 事件 |
| 召唤演出 | 召唤/特殊召唤/融合时，卡牌立绘居中放大展示 1s（名称+攻守横幅），王牌卡可配专属底纹 | DOM 层 + 事件钩子（fxevent 已有） |
| 结算演出 | 胜利：金色大字 + 光斑粒子 + 上滑按钮；失败：暗红大字 + 裂纹纹理；平局：灰白 | CSS + 少量 JS 粒子（canvas） |
| 伤害数字 | 扣血时飞溅 "-1200" 数字（已有 fx-dmg 基础，加强字号/轨迹/暴击感） | 现有 fxEl 体系 |

### A. HUD 装饰化
| 项目 | 说明 |
|---|---|
| LP 血条 2.0 | 斜切平行四边形 + 金属渐变 + 类型图标（LP/头像位），数字已有滚动，补碎片飞溅 |
| 阶段进度条 | 回合条上方 6 个阶段节点（图标+连线），当前阶段点亮，可点击跳转（保留 B 快捷键） |
| 顶栏装饰化 | 对局信息条加金色分隔纹样、圆角徽章化 |
| 按钮体系 | 全部按钮统一：图标 + 文案 + 快捷键角标 + hover 扫光（已有部分） |

### C. 菜单与面板美化
| 项目 | 说明 |
|---|---|
| 卡牌操作菜单 | 顶部加卡面缩略图、按动作类型着色的色条、图标对齐优化 |
| 卡牌预览大图 | 悬停预览升级为大图 + 类型框色 + ATK/DEF 徽章 + 效果文本分区 |
| 日志/帮助面板 | 玻璃拟态（毛玻璃+描边+投影），与整体装饰语言统一 |
| 卡组选择微调 | 已达标，仅补图标细节 |

### D. 3D 场景氛围
| 项目 | 说明 |
|---|---|
| 决斗盘装饰 | 场地边框加金属描边/发光纹理（贴花已有底子） |
| 召唤特效 | 召唤位置光柱 + 粒子上升（three.js Points） |
| 镜头运镜 | 召唤/攻击时轻微推拉镜头（现有 tween 体系可挂） |

## 四、建议实施顺序

**B（演出层）→ A（HUD）→ C（面板）→ D（3D）**。理由：B 是"像真实游戏"的决定性因素，全部基于现有 DOM/CSS 体系、不碰 3D 代码、风险低收益大；A 顺带强化信息可读性；C 是打磨；D 锦上添花可后置。

风格基准：Master Duel 的深色竞技场 + 金色仪式感（与现有主题同源，不推翻重来）。
